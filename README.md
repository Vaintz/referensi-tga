# Referensi Tugas Akhir

Repository ini digunakan sebagai arsip referensi ilmiah untuk penyusunan Tugas Akhir Program Studi Sistem Informasi.

## Topik Penelitian

**Optimasi Rute Evakuasi Dinamis pada Lingkungan Gedung Kampus Menggunakan Spatio-Temporal Heterogeneous Graph Attention Network (ST-HGAT) dan Proximal Policy Optimization (PPO).**

## Struktur Repository

Referensi dikelompokkan berdasarkan susunan subbab BAB II Tinjauan Pustaka.

| `2.3-Teori-Graf-dan-Pemodelan-Lingkungan-Evakuasi` | 2.3 | Teori graf dan representasi lingkungan evakuasi |
| `2.4-Graph-Neural-Network` | 2.4 | Graph Neural Network dan pembelajaran representasi graf |
| `2.5-ST-HGAT` | 2.5 | Spatio-temporal graph, heterogeneous graph, dan graph attention |
| `2.6-Reinforcement-Learning` | 2.6 | Reinforcement Learning dan Deep Reinforcement Learning |
| `2.7-Proximal-Policy-Optimization` | 2.7 | Algoritma PPO dan optimasi kebijakan |

## Data Master Referensi

File utama inventarisasi berada di `Data-Master-Referensi/MASTER-REFERENSI.md`. Gunakan file tersebut untuk mencatat metadata, metode, hasil, relevansi subbab, status pembacaan, dan nomor halaman temuan. Perbarui secara bertahap setelah setiap publikasi diperiksa.

## Cara Menambahkan Referensi

1. Pilih folder berdasarkan subbab yang paling sesuai dengan isi publikasi. Jika relevansinya masih umum atau lintas-subbbab, gunakan `Jurnal-Pendukung-Lainnya`.
2. Unggah file PDF ke folder tersebut.
3. Gunakan nama file yang mudah dikenali, misalnya nama singkat judul atau nama penulis dan tahun.
4. Jika satu publikasi relevan untuk beberapa subbab, simpan satu salinan utama dan catat relevansi tambahannya agar tidak terjadi duplikasi yang tidak perlu.
5. Periksa kembali metadata dan isi publikasi sebelum menggunakannya sebagai dasar pernyataan atau sitasi dalam naskah.

## Informasi Bibliografi

Untuk setiap publikasi, informasi berikut perlu dicatat saat proses inventarisasi:

- Judul publikasi
- Penulis
- Tahun terbit
- Nama jurnal atau konferensi
- Volume, nomor, dan halaman (jika tersedia)
- DOI atau URL resmi
- Metode penelitian
- Hasil utama
- Relevansi terhadap subbab Tugas Akhir

## Ketentuan Penggunaan

- Sitasi dan daftar pustaka dalam naskah Tugas Akhir mengikuti format IEEE serta pedoman program studi.
- Informasi bibliografi harus diverifikasi dari publikasi aslinya.
- Pengelompokan folder menunjukkan relevansi topik, bukan berarti seluruh isi publikasi otomatis dapat dijadikan dasar untuk setiap klaim.
- Perhatikan lisensi dan hak cipta masing-masing publikasi. Jangan mendistribusikan PDF secara publik apabila tidak diizinkan oleh pemegang hak cipta.
